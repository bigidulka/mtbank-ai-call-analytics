# ChatGPT Web + VAD + Luna experiment

Status: synthetic research profile only. Production and assignment submission continue to use the validated RunPod speech path.

## Pipeline

```text
audio
  -> unofficial loopback ChatGPT Web transcription (flat text)
  -> Luna typed semantic word ranges + Operator/Client roles
  -> FFmpeg `silencedetect` speech anchors
  -> merge adjacent same-role semantic ranges
  -> select `turn_count - 1` longest inter-anchor silences
  -> map semantic turns to acoustic groups in order
  -> bounded asymmetric VAD edge restoration
```

No reference text, timestamps, labels, filenames, or expected turn count enter inference. Expected turn count is produced by Luna from flat text. VAD is speaker-agnostic.

## Why it improved

Authored corpus uses orderly, non-overlapping turn-taking. Internal phrase pauses and inter-speaker pauses form distinct duration modes. Luna recovers semantic turn count/order; longest-gap ranking recovers boundaries without asking an LLM to solve timestamp arithmetic.

Direct `VAD anchors + Luna alignment` and proportional word-time alignment were rejected because they produced 67.58% and 76.98% time-weighted role accuracy respectively.

## Validation

A small grid over VAD noise threshold and edge restoration used leave-one-call-out selection. Every held-out call independently selected the same configuration:

```text
noise threshold: -45 dB
minimum silence: 0.25 s
start restoration: 0.2 s
end restoration: 0.9 s
```

Held-out macro DER: 1.78% (different aggregation from full-corpus micro DER 1.72%). Reproducible fold artifact is generated by `scripts/evaluate_vad_rank_loco.py`. This reduces within-corpus parameter-selection bias but does not provide an independent corpus.

## Critical claim boundary

This result demonstrates a strong fit to the authored synthetic corpus, not general diarization quality. Corpus construction uses:

- two clean Edge TTS voices;
- no overlap or interruption;
- fixed 800 ms silence inserted after every authored utterance;
- orderly two-party call-center turn-taking;
- no background noise or natural channel variation.

Longest-gap ranking exploits that structure. This is structural leakage from corpus generation into benchmark difficulty, even though reference values are not passed at inference. Leave-one-call-out calls share that same generator and therefore do not close this risk. It can fail when:

- speakers interrupt or overlap;
- natural within-speaker pauses exceed turn gaps;
- multiple consecutive turns have the same role;
- Luna predicts the wrong number/order of semantic turns;
- music, hold audio, packet loss, noise suppression, or codec artifacts distort VAD;
- more than two speakers participate.

Therefore candidate may be described as **better on this synthetic corpus**. It must not be described as better for real calls or as acoustic speaker identification. A blinded natural-call corpus is required before replacing RunPod.

## Security and availability boundary

The ASR gateway uses an undocumented ChatGPT Web endpoint and browser-session credentials. It is loopback-only but not an official OpenAI API contract. It may change or stop working and requires organizational approval before any real customer audio is sent externally.
